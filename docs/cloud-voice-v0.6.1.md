# v0.6.1-rc1 云端流式语音试用

语音输入新增“豆包云端 · 边说边出字”，可在“更多 → 设置与提醒 → 语音输入”选择。电脑本地识别继续保留。

- 手表通过 TLS WebSocket 直接连接火山引擎语音服务，不经电脑转发录音。
- 用户自行开通流式语音识别 2.0 并提供对应项目的语音 API Key，调用按服务方规则计费。
- 密钥通过本应用的 Android Keystore 加密保存在手表，不写入源码、安装包或日志。
- 每次录音最长 30 秒，边说边显示整句识别预览；再次点击麦克风结束录音。
- 已有草稿保留，识别结果检查、修改后由用户点击发送，不自动发送任务。
- 连接失败、暂停应用、切换确认目标时停止录音，不自动重传。
- 识别期间遇到只读状态或待确认请求，仍保留可用的停止按钮。

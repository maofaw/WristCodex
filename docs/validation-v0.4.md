# v0.4 验收记录

设备：OPPO Watch 4 Pro / Android 11 / 378×496 / 原生 DPI。日期：2026-10-20。

## 服务与构建

- 26 项 Python 测试通过，覆盖原认证、连续会话、目录分页、只读防写、跨对话目标校验、重启去重和过期定时器隔离。
- 隔离的真实 Codex 三轮验证：新建两段对话，返回第一段时正确恢复原暗号，不混入第二段上下文；测试对话已归档。
- Android 本地 Java/D8 编译、APK v2/v3 签名校验通过；GitHub Actions 另执行 Gradle Release 与 lintRelease。

## 真机功能

使用独立包名的临时测试包及 USB 转发服务验证，不覆盖正式连接口令或聊天内容：

- 两段草稿独立；从另一段返回当前对话仍保留原草稿；发送收到确认后仅清空对应草稿。
- 电脑记录明确只读且隐藏输入；其他对话有任务执行时隐藏发送入口并提供返回链接。
- 需要决定时的通知 Intent 指向实际任务对话；按钮提交明确的对话与回合，确认卡片优先于历史加载入口。
- 新建空白页不发出任务；历史向前分页与单条长消息按需读取。
- 测试服务断开后保留草稿，恢复联网不自动发送，测试发送计数保持不变。
- 搜狗仍为默认输入法。其全屏输入页属于输入法自身；检查进入和返回，无 DPI 修改。ADB 文字注入未作为成功输入的证据，草稿隔离采用固定测试草稿验证。

## 性能观察

这些是开发阶段的短样本，不是零卡顿或长期续航保证；两版本页面内容与采样帧数不同，不能视为严格基准排名。

| 指标 | v0.3 先前短滚动 | v0.4 长历史滚动 |
|---|---:|---:|
| 帧数 | 444 | 1321 |
| P50 | 6 ms | 5 ms |
| P90 | 17 ms | 18 ms |
| P95 | 21 ms | 20 ms |
| Janky frames | 70 | 343 |
| Frame deadline missed | 18 | 26 |

v0.4 长历史测试时 PSS 约 22 MB；另一轮初始 13.6 MB，十次列表/聊天往返后约 16.5 MB，仍为 1 个 Activity、0 个 WebView。v0.3 先前 PSS 约 15 MB。短样本中未发现持续叠加 Activity，仍有超过帧预算的帧，需要持续实测。

界面无装饰动画、无逐字重绘；展示记录最多 30 条，原生复用列表。网络等待与滚动分离，远程网络延迟仍会影响记录读取速度。

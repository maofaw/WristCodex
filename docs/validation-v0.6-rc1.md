## 已实现与开放边界

| 入口 | 本轮证据与当前状态 |
|---|---|
| 标准选择题、文字回答 | 真实桌面产生原请求，新版手表提交原选项，原桌面完成同一回合；重复、旧回合及内容版本校验有回归测试。 |
| 异步提问 | 识别原生 `agentMessage.questions`，保留题目/选项/原编号。已回答及终止回合会移除；未找到可可靠绑定原问题的回传接口，明确转电脑。 |
| 原生特殊选择卡片 | 保留说明，转电脑；不伪装为普通聊天回答。 |
| 执行计划、提出修改 | 计划摘要、按需全文与回电脑入口已接入；执行/修改按钮保持禁用。当前客户端没有已验证的原计划原子执行接口，不用“继续”代替。 |
| 命令、文件、网络授权 | 保留请求原有一次性允许/拒绝/取消；新增会话授权及结构化命令/网络规则仅展示详情，未经本机真实验证时逐项禁用并转电脑，服务端同时拒绝提交。旧协议只保留原有可处理选项，不臆造选项；没有可处理项时整体转电脑。本轮未完成全部类型的双端真实矩阵。自动审批不当人工请求。 |
| 额外权限 | 权限子集与回合/会话时长校验、原生手表选择控件及 HTTP 测试通过。界面夹具实测仅选择网络时没有提交文件授权；真实桌面请求尚未验证，写入口关闭。 |
| 简单工具表单 | 支持文字/布尔/整数/数字/枚举/多选的有界表单；字段校验及手表输入法、滚动、结构化提交通过夹具验证。真实桌面回传未验证，写入口关闭。登录、凭据、验证码、复杂表单转电脑。 |
| 失败处理 | 显示实际失败状态、继续输入及电脑入口；不捏造未支持的重试动作。 |
| 当前对话设置 | 实际模型目录读取、模型/思考强度/规划执行模式的原桌面更新与恢复通过接口实测；真机设置页分别修改模型、思考强度和模式，原桌面同步通过，未指定强度保持原值，验收后恢复原设置。仅影响当前空闲会话，变更有原设置条件及回执。 |
| 重命名 | 记录名称虽更新，但桌面所有者没有同步更新，因此保持不可用。 |
| 归档 | 本机原桌面仍持有写入所有权，记录接口返回 active writer，保持不可用。不会为了归档抢占原执行器。 |
| 已归档列表、恢复 | 分页读取及界面已实现；原生恢复接口已保留原编号、同步最近目录，并重新接上原桌面；新版手表从真实已归档列表提交恢复通过。正式环境未切换。 |
| 对话翻页 | 原生复用列表；左右滑动下一页/上一页在 378×496 真机通过。新建、前后页按钮、返回最近、刷新待处理均实际点击通过；断开专用 USB 测试端口时保持原页，恢复后可翻页。25 段合成待处理实际进入第二页。失败、边界、重复翻页另有 JVM 测试。 |

“有协议定义”“单元测试通过”“合成界面夹具通过”和“真实双端通过”分别记录，不互相替代。新写能力只允许由本机、当前桌面构建的验收证据开启；仓库不附带已开启能力文件。更新桌面或重连后重新核对构建，未知能力关闭。不能处理时仍可浏览共享记录并回电脑操作。

## 测试与复核

- Windows Codex 桌面构建：`OpenAI.Codex_26.1016.6573.0_x64__2p2nqsd0c76g0`。
- OPPO Watch 4 Pro / Android 11，378×496，现有密度 181 保持不变；原搜狗输入法未替换。
- Python 服务回归：125 项通过；HTTP 测试可独立运行，无需正式 TOKEN。全套桥接测试使用明确的测试凭据，与正式配置无关。
- Android `assembleRelease`、`lintRelease` 通过，47 个任务。Lint 无错误；保留广播接收标志、未使用资源、缺少应用图标及字符串国际化等警告，未宣称零警告。面向本设备的 targetSdk 30 未改。
- 真机还复现并修复不可选列表页首/页尾将根按钮禁用的问题，使用轻量原生容器保留按钮可点击，未加动画。待处理目录现携带真实可用性、原因及操作版本；旧协议降级同样生效。
- 一个独立全分支复核，修复了已答异步题卡住对话、未接受回答误消题、超长题标记随正文丢失、旧客户端看不全持久规则、明确未送达回答不能重试及英文凭据识别漏项。相关回归先失败后通过。
- 明确未执行的设置/管理操作可重新手动决定；送达未知及已接受的请求不自动重发，重启保留回执和草稿。正文预览不改变决策版本。
- 扩展授权单独验收门控；可用性变化只改变界面重绘键，不改变原请求操作版本。独立复核通过，覆盖原始一次性选项及旧协议兼容。
- 最终候选包在真机合成授权卡片实测：会话授权/网络规则禁用，原始“仅本次允许”可点且提交原选项。此项仅为界面夹具验收，不作为真实扩展授权接口证据。早先误连旧夹具的失败尝试不计通过；已停止同路径旧监听并重测。
- 暂缓次要项：直接向管理端点发送非法协议头时，错误响应路径可能关闭连接而非返回 400。正式手表固定发送合法协议 6，不受此边界影响。

## 复测入口

服务：`python -m unittest discover -s server`。Android：JDK 17+、SDK 35，运行 `assembleRelease lintRelease`；Windows 中文目录可在命令行使用 `-Pandroid.overridePathCheck=true`。不更改全局 Gradle 配置。

真实交互验收只使用单独命名的验收会话：先核对空闲状态、当前模型/强度/模式，逐项改动并观察原所有者同步，最后恢复原值。选择题必须在手表操作原请求并观察桌面完成；合成卡片不能作为原生接口通过的证据。归档/重命名必须同时检查历史和原桌面，不能只检查记录接口返回。

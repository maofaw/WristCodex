# 开源预览版范围：v0.6.1-rc3

日期：2026-10-22。

## 本次包含

- 当前 Android 原生应用、Windows 电脑服务、构建配置、测试和脱敏使用说明。
- 豆包云端流式语音、可选电脑本地识别及静态吉祥物图标。
- 既有共享会话、已验证的原生确认、分页及按当前机器实际能力开放的对话设置。
- MIT 许可保留上游署名，并注明 WristCodex 改动署名。

## 不随仓库分发

真实 `.env`、电脑连接口令、语音 API Key、桌面认证、个人地址、聊天记录、录音、状态文件、模型缓存与签名私钥。开发阶段的一次性电脑密钥填写页和个人启动任务不作为通用安装功能交付。

`androidTest` 中的 Keystore 检查、只读对比和 USB 配置探针仅属于测试组件；不会打包进 release APK。使用它们需要单独安装匹配签名的 instrumentation 包，不是公开的网络密钥接口。

## 验证边界

此前已在 OPPO Watch 4 Pro / Android 11 验证真实云端流式识别，用户确认边说边出字；正式应用经电脑临时配置后通过鉴权并进入录音。rc2 图标包已安装并检查 ONLINE。

本次源码复核修复录音中返回其他执行对话的边界，增加不可变草稿归属，主机回归覆盖旧结果不能写入其他对话且不改变原假设。新增的 Android 导航探针目前因设备未连接尚未运行；不以构建通过替代真机验收。

计划执行、异步题回传、扩展权限／表单、重命名和归档仍有未验证或桌面限制，按实际能力关闭。内部原生 IPC 随客户端升级可能变化；当前未提供多账号隔离或完整换号流程。所有公开包仍以预发布标记，不声称生产稳定版。

构建／CI、发布标签和校验值以对应提交和 Releases 附件为准。历史验证分别见本目录的版本验收文档，不能自动视作本次所有场景重测通过。

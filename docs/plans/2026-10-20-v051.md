# v0.5.1：对话优先、桌面兼容与及时回复

用户已批准本计划。当前分支基于 v0.5.0 的 011820f。

## 约束
- 黑底终端绿、系统字体、原生复用列表，无装饰动画；触控至少 48dp。
- A 布局：标题切换对话、可见更多、固定状态/待处理行、消息列表、文字输入、宽麦克风与唯一发送。
- 保留对话、草稿、历史、配置、提醒开关、电脑控制、自定义接口；模型与思考强度不变。
- 不修改桌面程序或数据库，不增加模型执行器，不自动重发送达未知请求。

## Task 1：原生协议与回复预览
- 先加入重现缺少 text_elements 的桌面渲染契约测试，再统一原生文字输入编码。
- 正确跟踪当前回合 assistant message 的完整和增量补丁，包括消息替换、回合切换、版本缺口。
- 兼容扩展状态接口 reply_preview：{thread_id,turn_id,item_id,text,version,complete,clipped}；无正文时为 null。text 最多 1000 字符，version 在同一消息内单调递增。complete 只在该回合完成/失败/中断后为 true；不泄露 reasoning。
- 首段正文、完成、确认立即发布；后续正文最多每秒一次。桌面原生状态持续接收，保留最终结果与分页历史；旧客户端可忽略预览。
- 使用请求编号记录电脑接收、native 接收、首段与完成耗时；日志不包含正文、令牌或完整接口地址。
- 测试旧请求去重、权限继承、跨会话确认和节流行为。

## Task 2：A 首页、完整入口、手表预览与重连
- 控制提交独立于历史/语音后台工作；取消过期读取，导航和请求回调隔离。
- 提交立即反馈，确认接收后按原请求清空，保留提交后继续输入的新草稿。
- 原生列表仅更新变化行，预览按会话/回合/消息定位，浏览历史不跳动；预览全文本地分页，完成后替换为正常历史，最多 30 条展示记录。
- 更多含刷新、返回执行、停止（再次确认）、电脑控制、设置与提醒。设置保留电脑确认开关、自动弹出授权、暂停全部提醒、连接及自定义接口。
- 单长轮询，失败 1/2/4/8/15 秒可打断退避；网络恢复或手动刷新立即重连，不发送任务。
- 记录本地发送/首段显示/完成显示用时，避免时钟跨设备相减。

## Task 3：集成、验收与私有试用版
- 服务全部测试、Android 构建和 lint、独立审查。
- 真桌面与手表交替至少 20 回合，验证桌面无渲染错误，新建/切换/确认/停止、长文和首段时延。
- 真机 378×496：输入法、触控、草稿隔离、断网恢复、无重复任务、提醒去重与开关。
- 同条件三轮对照旧版和已装哔哩终端的滚动，30 次切换/反复进入，记录帧耗时、卡顿和内存；退步先简化。
- 全部验收通过后才发布私有 v0.5.1（versionCode 9），保留回退包与配置备份。任何未通过项如实记录，不宣称完成。

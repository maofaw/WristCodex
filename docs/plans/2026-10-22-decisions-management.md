# 腕上遥控：决策入口与基础会话管理（已批准）

来源：2026-10-22 用户直接提交的实施计划；先决策后基础管理，保持极简原生界面和流畅性。

## 不变约束
- 同一台 Windows 本地 Codex 原所有者执行；不模拟点击、不改聊天数据库、不启动替代执行器。
- 未验证的接口和必须登录/系统验证的流程明确转电脑，不算接通；支持旧客户端。
- 对话/回合/请求/操作版本绑定，双端先处理失效，送达未知不重发；自动审批不当人工确认。
- 模型/思考强度/规划执行模式仅当前对话空闲时改变；不改全局默认。
- 配置、会话、草稿、提醒偏好及既有送达凭据保持；当前早期 0.5.1 为回退与性能基线。
- 单长轮询；列表20项，历史首读10项，最多展示30条；长文分页，无装饰动画。

## Task 1: 决策协议与安全提交
- 核对本机桌面版本；标准/异步提问、选择卡片、计划执行/修改、命令/文件/网络/额外权限、简单工具表单。
- 识别并展示所有人工决策；仅验证可完整提交的类型开启操作。敏感/复杂/未知请求回电脑。
- 操作版本不随预览更新改变；去重、失效和未知送达保留；旧协议降级。
- 红绿测试：跨会话/回合、版本变化、自动审批、原始选项、权限子集、表单验证和重复/未知提交。

## Task 2: 基础管理与接口
- 当前对话设置读写及实际模型/强度/模式能力；重命名、归档、已归档列表、恢复。
- 只走已验证原客户端操作；归档二次确认且空闲无待处理；未知接口返回具体不可用原因。
- 扩展状态/待处理/回答与能力声明；增加有身份和版本校验的管理接口，不提供任意RPC代理。
- 红绿测试：设置隔离/忙碌拒绝/回执、归档恢复编号一致、兼容和API验证。

## Task 3: 原生手表界面与翻页
- 决策卡片按种类展示原选项、表单和分页详情；提醒沿用开关与一次性定位。
- 更多新增当前对话设置、对话管理；首页不堆按钮。
- 列表左滑下一页/右滑上一页，按钮+页码+返回最近；48dp水平位移且>纵向1.5倍；左右24dp留系统；读取期间禁翻页，失败不换页。
- 单页20项，记录游标不累积列表；首/末页禁用；未知类型回电脑。
- JVM检查：页码游标的成功/失败/重复/恢复与手势边界；Android构建/lint。

## Task 4: 验收、回顾与两批私有试用
- 真实桌面逐类验证双方先处理、多会话、过期、断连及未知送达；计划正确模式且不重复执行。
- 真机378×496输入法/通知/系统返回；同条件和早期0.5.1对比生成滑动、30次切换、反复进入的帧耗时/卡顿/内存。
- 全分支独立审查；发布前签名、保留回退APK，附已接通/转电脑/未通过清单。
- 未达到某批真机或接口验收门槛不发布为该批完成；不擅改当前服务或手表。

## 本轮不做
搜索、置顶、项目选择、分叉、编辑重试、上下文压缩、全局设置、任务队列、多电脑/云端。

# 完成提醒 0.6.3-rc1

## 行为

- 本机桌面共享接口实际同步的本地对话：先观察到同一回合执行，再观察到成功完成、可发送且无待处理请求，生成一次完成事件。
- 完成短振一下（180ms），新确认沿用两下。多个完成同批合并；同批有新确认时优先确认，不叠加完成短振。
- “更多 → 设置与提醒 → 任务完成振动”独立持久开关，候选默认开启。总暂停、通知禁用、静音与勿扰仍生效。
- 完成不主动亮屏、不抢占当前聊天。失败、停止、首次完成历史、只读或未同步的会话不触发。

## 接口与状态

原状态和事件响应新增 `completion_notifications`：`available`、`scope`、`cursor`、`oldest`、`events`。事件包含sequence、thread_id、turn_id、title；最多缓存64条事件，旧客户端可忽略新增字段。

手表仍只有一条长轮询，先持久保存去重游标再振动。首次连接、重连及事件缺口建立静默基线；关闭/暂停期间推进游标，启用/恢复先在后台取得明确服务端切点。设置切点与网络代次复位协调，旧响应不能触发新连接。振动失败不自动补振。

保留此前安装版的会话缓存、网络参数分类配置、确认记录与兼容振动逻辑；不加入已作废的新UI布局，不修改桌面数据库，不另开模型执行器。电脑端去重身份保留到scope复位，不将所有元数据宣称为64条有界。

## 构建与发布

使用项目既有Android构建方式及 `python -m unittest discover -s server`，服务测试需设置一次性测试用 `WATCHREMOTE_TOKEN`；不得使用个人生产令牌。

手表与电脑服务请配套更新。该提交同步源码；没有新建Release或替换历史安装包。源码不包括个人配置、真实密钥、对话记录、设备能力回执或私有验收日志。
